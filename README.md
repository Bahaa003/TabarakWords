# تطبيق كلمات تبارك وعمّ

تطبيق أندرويد لحفظ ومراجعة الكلمات الغريبة في جزأي "عمّ" و"تبارك" بأسلوب البطاقات
التعليمية (Flashcards)، مبني بـ Kotlin + Jetpack Compose + Material 3 + Room
وفق نمط MVVM.

## طريقة التشغيل
1. افتح مجلد `project` هذا مباشرة في **Android Studio** (Hedgehog أو أحدث).
2. عند أول فتح سيطلب منك Android Studio مزامنة Gradle — اسمح له بذلك (سيقوم
   تلقائيًا بتنزيل `gradle-wrapper.jar` المطلوب لأن `gradle-wrapper.properties`
   موجود بالفعل ويشير إلى Gradle 8.7).
3. شغّل التطبيق على محاكي أو جهاز فعلي (الحد الأدنى Android 8.0 / API 26).

## البيانات
- جميع الكلمات ومعانيها مستخرجة من ملف "تفسير جزأي عمّ وتبارك" المرفق، ومخزّنة
  في `app/src/main/assets/words.json` (522 كلمة موزعة على 44 سورة).
- عند أول تشغيل للتطبيق تُقرأ هذه البيانات وتُنسخ تلقائيًا داخل قاعدة بيانات
  Room محلية (`tabarak_words.db`)، وبعدها يعمل التطبيق بالكامل دون إنترنت.
- كل كلمة تحمل حقل `needs_review`؛ وُسمت به كلمتان فقط ظهر فيهما التباس بسيط
  في تنسيق الجدول الأصلي، ويُنصح بمراجعتهما يدويًا مقابل المصحف المفسَّر إذا
  أردت دقة مطلقة 100%.

## الميزات المطبَّقة
- الشاشة الرئيسية: اختيار جزء عمّ / جزء تبارك.
- قائمة السور داخل كل جزء، ثم قائمة كلمات كل سورة (مع إمكانية الإضافة للمفضلة).
- بطاقات تعليمية (Flashcards) قابلة للقلب: تعرض الكلمة فقط، ثم تكشف المعنى،
  مع أزرار التالي/السابق.
- اختبار حفظ: يعرض الكلمة، تضغط "أعرفها" أو "لا أعرفها"، فيظهر المعنى فورًا
  وتُحفظ نتيجتك، ثم تنتقل تلقائيًا للكلمة التالية، وفي النهاية تظهر لك نتيجتك.
- مراجعة عشوائية: 30 كلمة عشوائية من كل السور (بطاقات أو اختبار).
- بحث سريع فوري بالكلمة أو بجزء من المعنى.
- صفحة إحصائيات: العدد الكلي، عدد المراجَع، نسبة الإنجاز، عدد "أعرفها"
  وعدد "لا أعرفها".
- مفضلة: إضافة/إزالة أي كلمة، ومراجعتها لاحقًا كبطاقات مستقلة.
- حفظ تلقائي كامل لكل تقدمك (Room + Flow) بدون أي إجراء يدوي.
- دعم كامل للعربية RTL، Material 3، والوضع الليلي التلقائي (يتبع إعداد النظام).

## البنية المعمارية (Clean/MVVM)
```
data/        → WordEntity, WordDao, AppDatabase, JsonSeeder, WordRepository
ui/          → شاشة + ViewModel لكل ميزة (home, surah, words, flashcard,
                quiz, random, search, stats, favorites)
ui/theme/    → ألوان وخطوط وثيم Material 3
ui/navigation/ → مخطط التنقل الكامل بـ Navigation Compose
util/        → أدوات مساعدة لإنشاء ViewModel مع تمرير Repository
```

## ملاحظة حول أيقونة التطبيق
الأيقونة الحالية أيقونة تكيّفية (Adaptive Icon) بسيطة مرسومة كـ Vector (كتاب
مفتوح بألوان الغلاف الأصلي)، ويمكنك استبدالها بسهولة عبر Image Asset Studio
داخل Android Studio (زر يمين على `res` ← New ← Image Asset) إن رغبت بتصميم
احترافي أدق.
